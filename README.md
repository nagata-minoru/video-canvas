# Video Canvas

ブラウザ上に任意サイズの「動画キャンバス」を作り、その中に動画素材を配置してクロップ・演出するためのページです。

最終的にはブラウザ画面を録画（OBS・QuickTime Player・macOS画面収録など）して動画素材として利用することを想定しています。iMovie などでは自由に指定しにくい**任意の縦横比・解像度によるクロップ**を、ブラウザ上で正確に実現します。

## 設計思想

「動画そのものをクロップする」のではなく、「**クロップされたキャンバス（`overflow: hidden` の div）の中に動画を自由配置する**」という考え方を採用しています。

キャンバスサイズ（例: 1080×608）は動画本来の解像度とは独立して指定でき、動画がキャンバスより大きくても小さくても、自由に位置・拡大率を調整できます。キャンバスからはみ出した部分は表示されません。

## 技術スタック

- [Vite](https://vitejs.dev/)
- Vanilla TypeScript（フレームワークなし）
- 外部ライブラリへの依存なし（ドラッグ操作はネイティブの Pointer Events API を使用）

## 使い方

1. 画面上部の「キャンバス」欄で幅・高さをピクセル単位で指定します。
2. 「動画を追加」からローカルの動画ファイルを選択します。
3. Fit で `Cover` / `Contain` / `原寸(Custom)` を切り替え、動画のキャンバスへの配置方法を選びます。
4. キャンバス内の動画をドラッグすると位置を移動できます。Scale のスライダー・数値入力で拡大率を調整できます（中心を軸に拡大縮小されます）。
5. 下部の再生ボタン・シークバーで動画の再生・一時停止・シークができます。
6. 仕上がったキャンバス領域を OBS のブラウザソースや画面収録機能でキャプチャし、動画素材として書き出します。

## ファイル構成

```
src/
├── main.ts          エントリーポイント。DOM取得と各モジュールの初期化・結線のみ
├── style.css         レイアウト・見た目
├── types.ts          CanvasConfig / VideoLayerModel / FitMode の型定義
├── canvas.ts          CanvasController: キャンバス要素のサイズ管理
├── fit.ts             純粋関数: cover/contain/custom のボックス計算ロジック
├── videoLayer.ts      VideoLayer クラス: <video> 要素の生成・状態保持・再生制御・transform適用
├── drag.ts            attachDrag(): Pointer Events による汎用ドラッグヘルパー
└── controls.ts        全UIコントロールとモデル/DOMの結線
```

## 現在のスコープ

最初のバージョンとして、以下の機能のみを実装しています。

- キャンバスサイズ指定
- 動画の読み込み・再生・一時停止・シーク
- 動画素材の拡大・縮小（Scale）
- 動画素材のドラッグによる X/Y 移動
- COVER / CONTAIN フィット
- クロップ表示（`overflow: hidden`）

以下は今後追加予定の機能で、現時点では未実装です。

- キーフレームによるアニメーション
- フェードイン・フェードアウト
- 回転
- テキスト・画像レイヤー
- 複数動画の重ね合わせ
- 音量調整
- タイムライン編集
- プロジェクトの保存
